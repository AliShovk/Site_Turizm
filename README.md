# Отель «Проспект» — прототип сайта

Кисловодск, пр-т Победы, 10Б · 4★ · 24 номера · 4,8 при 639 отзывах

Демонстрационный прототип сайта гостевого объекта под продажу: карта и схема подъезда,
вызов такси, онлайн-бронирование, каталог номеров с фотографиями. Собран как материал
для разговора с собственником — на его же реальных данных и фото.

## Что внутри

| Папка | Содержимое |
|---|---|
| `01_Сайт/` | `Прототип_сайта_Проспект.html` — главная демо-страница; `Фото_номеров_Проспект.html` — галерея 33 фото по 7 категориям |
| `02_Фото/` | `номера/` — 33 фото 1024×683 по категориям; `отель/` — 4 общих фото |
| `03_Материалы/` | досье объектов (юрлица, ЛПР, цены, скрипты звонков) и список лидов СКФО (xlsx) |
| `04_Исходники_сборки/` | python-скрипты, которыми собраны страницы и данные |
| `index.html` | стартовая страница проекта со ссылками на всё перечисленное |

## Что реализовано в прототипе

- **Карта и подъезд**: реальная точка (43.91332, 42.71949), маркеры, маршруты на авто / пешком / 2ГИС, схема подъезда и парковки по шагам, заезд после 22:00.
- **Такси**: кнопки Яндекс Go и Maxim с уже подставленным адресом отеля, звонок на ресепшн.
- **Бронирование**: форма дат, кнопки ведут в действующий модуль ReservationSteps отеля.
- **Номера**: 7 реальных категорий с площадью, типом кроватей и мини-галереями (клик по превью меняет фото в карточке).
- **Мобильная версия**: липкая панель «Забронировать / Позвонить / WhatsApp».

## Оговорки

1. Фотографии взяты из публичной карточки отеля — для рабочего сайта нужно разрешение
   собственника либо исходники от администратора.
2. Цены: «от 6 200 ₽» — реальный минимум по объекту. По остальным категориям цена
   зависит от дат заезда и подставляется календарём брони.
3. Точки въезда, число парковочных мест, телефоны местных такси помечены в прототипе
   как требующие уточнения — выдуманных данных нет.
